# Open Source Collaboration & Contribution Management System

A DBMS course team project for managing organizations, projects, issues, contributions, reviews, and related collaboration workflows.

> **Status:** Initial planning and database design. The implementation and tech stack are not finalized yet.

## Team workflow

We plan work through GitHub Issues, claim one active issue per team member, implement it on an issue branch, and merge it only after peer review.

Read [CONTRIBUTING.md](CONTRIBUTING.md) before claiming an issue or opening a PR.

## Project documentation

The ER diagram, database schema, module interfaces, setup instructions, and architecture decisions will be added as the team finalizes them.
